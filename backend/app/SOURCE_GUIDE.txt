backend/app source guide
========================

Inline comments explain source files and named operations. Existing comments and docstrings are retained.
JSON and image files are described here because their data should remain unchanged.
Tests, migrations, operational scripts, dependencies, and generated files are outside this source-only scope.

__init__.py
  Mark app as the importable root package for the backend application.

core/auth_dependencies.py
  Resolve the signed-in database user and enforce account status and platform roles before protected endpoints run.

core/config.py
  Validate backend environment settings before startup, including database, CORS, TLS, rate limits, and integration configuration.

core/database.py
  Create the shared SQLAlchemy engine and request-scoped sessions, applying the configured database TLS policy.

core/db_maintenance.py
  Check database targets and identities before maintenance operations so a mistaken connection is rejected.

core/driver_document_body_limit.py
  Constrain driver-document multipart uploads while the request body is being parsed.

core/http_security.py
  Apply CORS, host checks, request limits, and safe HTTP error handling consistently across API routes.

core/rate_limit.py
  Apply request budgets to authentication and application operations to limit repeated or abusive calls.

core/request_limits.py
  Bound request bodies before endpoint processing to avoid accepting unbounded payloads.

core/security.py
  Hash and verify passwords and sign expiring access tokens so authentication never stores plaintext passwords.
